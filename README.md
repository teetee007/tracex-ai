# TraceX AI

Evidence-first digital forensics prototype. TraceX AI loads authentication, web-server and
system logs, normalizes them into one timeline, links related events across sources and
reconstructs a plausible attack — with every conclusion traceable to the original log line.

Built for the CS3405 Ethical Hacking and Penetration Testing hackathon. See
[PLAN.md](PLAN.md) for the schedule and [THREAT_MODEL.md](THREAT_MODEL.md) for scope and assumptions.

## Setup (Windows)

Requires Python 3.10+.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python scripts/generate_synthetic_logs.py   # (re)creates data/tc01_attack/
streamlit run app.py                         # opens http://localhost:8501
pytest                                       # runs the test suite
```


## Evidence references

Every event has a `raw_ref`: `auth.csv:17` is line 17 of the file (line 1 is the header);
`web_access.json#42` is the record at index 42 of the JSON array. Findings must cite these.

## Data and ethics

- All logs are synthetic, generated by `scripts/generate_synthetic_logs.py` with a fixed seed.
- External IP addresses are from RFC 5737 documentation ranges (`203.0.113.0/24`, `198.51.100.0/24`).
- No real users, credentials or production logs are used. API keys (when the AI layer is added)
  are read from environment variables and never committed.

## Current limitations

- Syslog-style timestamps have no year; the year comes from `dataset.json`.
- All timestamps are assumed UTC unless the source gives an offset.
- Detection thresholds (e.g. 5 failed logins in 10 minutes) are fixed values in
  `tracex/detections.py`, chosen for the synthetic scenarios, not tuned on real traffic.
- System commands are attributed to a login by user + host + time (the system log has no
  session ID); these links are labelled **inferred**.
- The attack graph, ATT&CK mapping and AI investigator are not implemented yet (see PLAN.md).
- After editing code in `tracex/`, restart `streamlit run app.py`; cached data otherwise stays stale.
