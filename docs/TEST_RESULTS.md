## Known limitations

- Rules and thresholds were written for these scenarios; slow attacks below the 5-failures-in-10-minutes threshold are not detected.
- Clock skew is detected only when a host's commands appear before the login that must precede them; a clock running ahead cannot be detected this way.
- Host commands are linked to a login by user + host + time (inferred), because the system log has no session ID.
- Mitigation results are a replay over recorded logs; an attacker who adapts is not modelled.
